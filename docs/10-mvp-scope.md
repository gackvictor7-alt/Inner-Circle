# MVP-Umfang vs. Vollprodukt

## Warum ein MVP?

Das Vollprodukt (alle 10 Bereiche + alle Workflows) ist zu groß für
einen Big-Bang-Launch. Der MVP beweist: Menschen registrieren sich,
zahlen, vernetzen sich und erleben echten Wert – der Rest folgt
nachfragegesteuert.

## MVP (empfohlener Launch-Umfang)

**Schritte 01–07 + 16 (Basis) + notwendige Admin-Minima:**

1. Fundament, Designsystem, öffentliche Website (01–03).
2. Konten + Auth (04), Mitgliedschaft + Stripe + Trial (05).
3. Dashboard + Profile (06).
4. Netzwerk: Verzeichnis, Connect, 1:1-Chat, Benachrichtigungen (07).
5. Events-Basis: entdecken, buchen, Tickets (16 light).
6. Admin-Minima: Mitglieder, Abos, Freigaben, Moderation, Audit (aus 17 vorgezogen).
7. Rechtstexte v1 (geprüft), E2E-Tests, Security, Deployment (18–20 light).

**Bewusst NICHT im MVP:** Deal-Räume/Brokerage-Vollausbau (10),
Investment-Ausführung (nur Discovery-Vorbereitung), Marktplatz-Vollausbau
(12–13), Referral-Auszahlungen (14, Tracking ggf. vorbereitet),
Trust-Score-Vollsystem (15, Basis vorbereitet), exklusive Experiences.

## Vollprodukt (Zielbild, alle 20 Schritte)

Alle Bereiche A–J inkl. Deal-Räume, Provisions-Engine, Investment-
Discovery mit regulierten Partnern, Marktplatz + Academy, Creator-
Programm, Trust-System, Event-Vollausbau, Admin-Zentrale.

## Größte Abhängigkeiten & Risiken

| Bereich | Abhängigkeit | Umgang |
| ------- | ------------- | ------ |
| Recht | AGB/Datenschutz, Provisionsordnung, Investment-Lizenzen, Marktplatz-/Steuerfragen | Früh Rechtsberatung budgetieren; ohne Freigabe bleiben Ausführung/Provisionen deaktiviert |
| Zahlungen | Stripe-Verifizierung, später Connect/PayPal | Testmodus zuerst; Live erst nach Tests + Freigabe |
| Vertrauen | Echte Mitglieder, echte Deals, echte Events | Keine Fake-Inhalte; MVP klein + echt starten |
| Kosten | Free-Tier-Grenzen bei Wachstum | Monitoring; Pro-Tarife erst bei Umsatz |
| Technik | E-Mail-Zustellbarkeit, Storage-Rechte, Webhook-Sicherheit | Checklisten in Schritt 04–06/19 |

## Offene Gründer-Entscheide (gesammelt)

1. Finaler Markenname (INNER CIRCLE ist Arbeitsname).
2. Jahrespreis der Mitgliedschaft.
3. Provisionsordnung (Sätze je Deal-/Marktplatz-Kategorie).
4. Investment-Partner/Struktur (nach Rechtsberatung).
5. Launch-Umfang final: MVP wie oben oder erweitert?
6. Erste Event-Formate + Preise.
