# Zugangsstufen, Rollen & Berechtigungen (Zielbild)

**Prinzip:** Zwei getrennte Achsen –
**(1) Mitgliedsstatus** × **(2) Aktivitätsfreigaben**.
Rollen-Selbstbeschreibung ≠ Berechtigung (z. B. „Investor" als Profilrolle
öffnet keine regulierten Funktionen).

## Achse 1: Mitgliedsstatus

| Stufe | Voraussetzung | Kernrechte |
| ----- | ------------- | ---------- |
| **Besucher** | keine | Öffentliche Seiten, Previews, Registrierungs-/Login-Seiten |
| **Registriert (kostenlos)** | Konto + E-Mail-Verifizierung | Discovery-Dashboard, 48-h-Trial (eingeschränkt), Lern-Previews, öffentliche Profile |
| **Mitglied (bezahlt)** | aktives Abo (Monat/Jahr) | Netzwerk, Deals, Investments (Discovery), Marktplatz-Kauf, Events, Nachrichten, Gruppen |

**Trial-Regeln:** 48 h ab Registrierung, keine Zahlungsdaten, kein
Auto-Charge; danach automatisch kostenlos-Status. Trial-Nutzer:
kein Spammen, keine vertraulichen Investments, keine veröffentlichten
Angebote.

**Abo-Regeln:** Kündigung im Konto; aktiv bis Periodenende; danach
kostenlos-Status; Profildaten bleiben gemäß Datenschutzregeln erhalten.

## Achse 2: Aktivitätsfreigaben (zusätzlich zum Mitgliedsstatus)

| Freigabe | Wofür | Vergabe |
| -------- | ----- | ------- |
| Verkäufer | Marktplatz-Angebote publizieren | Antrag + Admin-Freigabe (ggf. je Kategorie) |
| Creator/Partner | Referral-Links, Akquise-Provisionen | Bewerbung/Einladung + Admin-Freigabe |
| Investment-Publisher | Chancen einreichen | Unternehmens-Antrag + Admin-Prüfung |
| Investor (qualifiziert) | Sensible Investment-Details | Eignungsprüfung (rechtlich definiert, Schritt 11) |
| Event-Gast (exklusiv) | Premium-Formate | Bewerbung/Einladung, Betreiber-Entscheid |
| Gruppen-Admin | Gruppe moderieren | Gruppen-Owner/Admin-Vergabe |
| Firmen-Admin | Firmeneintrag verwalten | Nachweis + Verifizierung |
| Admin/Operator | Betriebs-Dashboard | Rollenbasiert, protokolliert (Stufen: Support, Moderation, Finanzen, Super-Admin) |

## Anerkennung ≠ Berechtigung

- **Founding Member** (erste 50, Admin-Prozess), Leistungs-Badges,
  Leaderboards: sichtbar, aber öffnen **keine** sensiblen Funktionen.
- **Trust Score:** nur aus verifizierten Kollaborationen (1–5, Dezimal);
  Start ohne Wert („Noch keine verifizierten Bewertungen").
